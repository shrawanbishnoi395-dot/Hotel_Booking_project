# 🏨 Hotel Booking Analytics & Cancellation Prediction

An end-to-end Data Analytics & Machine Learning project that analyzes hotel booking behavior, extracts business insights, predicts booking cancellations, and presents results through an interactive Power BI dashboard.

---

## 📌 Project Overview

This project focuses on understanding hotel booking patterns and identifying factors that influence booking cancellations. The workflow includes data cleaning, exploratory data analysis, feature engineering, machine learning model development, and business intelligence visualization.

---

## 🎯 Objectives

- Analyze hotel booking trends
- Identify cancellation patterns
- Generate business insights
- Build a cancellation prediction model
- Create an interactive Power BI dashboard
